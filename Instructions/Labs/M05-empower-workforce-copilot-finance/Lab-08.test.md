# Lab-08: Exercise 2, Task 1 — Use Microsoft 365 Copilot Chat to Evaluate Vendor Contracts

## Lab Overview

In this lab, you use **Microsoft 365 Copilot Chat** to perform a side-by-side comparison of two vendor contracts — one from **Adatum Corporation** and one from **Contoso, Ltd.** You will identify key differences, highlight risk areas, and surface negotiation opportunities. The analysis you produce in this lab will serve as the foundation for the PowerPoint presentation you create in Lab-09.

**Estimated Duration:** 20 minutes  
**Difficulty Level:** 200 (Intermediate)

---

## Learning Objectives

By the end of this lab, you will be able to:

- Use **Microsoft 365 Copilot Chat in Work mode** to compare two legal/commercial documents simultaneously.
- Identify key contractual differences in pricing, delivery, warranties, and liability terms.
- Add multiple analysis sections to a Word document using Copilot in Word with **Edit with Copilot**.
- Build a comprehensive contract comparison document that will serve as the source for downstream deliverables.

- Completion of **Lab-01** (resource files uploaded to OneDrive).
- Completion of **Lab-07** (Exercise 2 orientation and scenario context).

## Background and Scenario

### The Contract Review Assignment

Fabrikam's Finance Manager has shared two vendor contracts with you:

| Vendor | Contract Type |
|--------|--------------|
| **Adatum Corporation** | Smart sensor component supply contract |
| **Contoso, Ltd.** | Smart sensor component supply contract |

Both contracts contain clauses related to pricing, delivery schedules, warranty terms, and penalties for nonperformance. You need to:
- Understand how the contracts **differ** from each other.
- Identify which contract **poses greater financial or operational risk** to Fabrikam.
- Determine **negotiation points** Fabrikam could raise to improve terms.

The final output of this task — a Word document called **Smart Sensor contract comparison** — will become the source material for your PowerPoint presentation in Lab-09.

## Understanding Copilot Chat Modes

| Mode | When to Use | Response Selector |
|------|-------------|-------------------|
| **Work** | Analyzing internal files (OneDrive, SharePoint, Teams) | Not shown; automatically managed |

> ✅ **For this task, use Work mode** — you are comparing files stored in your OneDrive.

## Task Instructions

### Step 1: Download and Upload Both Vendor Contracts

1. Select the following links to download both vendor contracts:
   - [**Adatum Corp smart sensor contract.docx**](https://go.microsoft.com/fwlink/?linkid=2347801)
   - [**Contoso Ltd smart sensor contract.docx**](https://go.microsoft.com/fwlink/?linkid=2347516)

2. Save both files to your **OneDrive** account.

---

### Step 2: Open Copilot Chat in Work Mode

1. In Microsoft Edge, navigate to the **Microsoft 365 home page**: `https://www.microsoft365.com`

2. Select the **Work** option in Copilot Chat to ensure Copilot searches your internal OneDrive and organizational content.
   - If Copilot Chat is not already open, first select **Copilot** from the left navigation pane (or from the app launcher), then switch to **Work** near the top of the chat experience.

3. In the prompt field, attach **both vendor contract files** that you downloaded in Step 1.
   - If needed, use the **Attach** / paperclip icon (or **+** if shown) to browse to the two files.

> **📸 Screenshot placeholder:** Capture Copilot Chat in **Work** mode with both vendor contract files attached in the prompt field before you submit the request.  
> Suggested filename: `M05-Lab08-Step01-BothContractsAttached.png`

> ✅ **Checkpoint:** Both contract files should appear as attachments in the Copilot prompt field before you submit your request.

> **🔧 Troubleshooting:**
> - If you cannot attach both files at once, attach one file first, submit the prompt, then start a new conversation and attach both again.
> - If the **Edit in Pages** icon does not appear, scroll to the very bottom of Copilot's response where action icons typically appear.
> - If Word opens in desktop app instead of Word for the web, save the document to OneDrive first, then reopen from OneDrive in the browser.
> - If Copilot in Word does not show **Edit with Copilot**, your account may not have Copilot enabled for Word. Contact your lab administrator.
> - If the document name does not save, select the title text area above the ribbon and type the new name directly.

---

### Step 3: Submit the Contract Comparison Prompt

Ask Copilot to compare the two contracts using the following prompt. This prompt is provided as a complete model that demonstrates how to incorporate all four key elements (Goal, Context, Sources, Expectations):

> **I'm a Financial Analyst at Fabrikam, Inc., evaluating two vendor contracts as part of a Cost Optimization and Risk Reduction initiative. The contracts are for components supporting our new smart sensor product line. Can you please compare the contracts from Adatum Corporation and Contoso, Ltd. to identify key differences that could affect Fabrikam's costs, supplier risk, and long-term financial performance. Use the two attached vendor contracts as reference materials. Focus on clauses related to pricing, delivery timelines, warranties, and liability or penalty terms. Provide a clear, bulleted summary that highlights major differences between the two contracts, identifies which contract poses higher financial and operational risk to Fabrikam, and suggests two or three negotiation points Fabrikam could raise to improve terms.**

> 💡 **Note:** This prompt is provided in full as a reference model. Observe how it specifies the analyst's role (Goal + Context), references both contract files (Sources), and requests bulleted output with three specific outcomes (Expectations). Use this structure as a guide for all subsequent prompts.

**After Copilot responds:**
- Review the comparison carefully.
- Check that Copilot has addressed: major differences, higher-risk contract, and negotiation points.

> ✅ **Expected Outcome:** A bulleted comparison identifying key contractual differences across pricing, delivery, warranties, and liability — including a risk assessment and negotiation recommendations.

> **📸 Screenshot placeholder:** Capture the Copilot response showing the completed contract comparison, risk assessment, and negotiation recommendations.  
> Suggested filename: `M05-Lab08-Step02-ContractComparisonResponse.png`

### Step 4: Save the Analysis to a Word Document

1. At the end of Copilot's response, select the **Edit in Pages** icon.
   - The icon typically appears in the bottom-right action area of the Copilot response and looks like a **page with a pencil/edit symbol**.

> **📸 Screenshot placeholder:** Capture the bottom-right action area of the Copilot response with the **Edit in Pages** icon visible.  
> Suggested filename: `M05-Lab08-Step03-EditInPagesOption.png`

2. In the Pages form that appears alongside the Copilot chat pane, select the **Create** button, then select **Document** from the drop-down menu.
   - This is the action path that creates a Word document from the Copilot response.

3. In the dialog box, select **Open Word**. This opens a new Word document in Word for the web containing Copilot's full response.

4. In Word, delete any **extraneous chat content** that was pasted in (such as introductory or closing phrases that are not part of the analysis).

5. Select the file name above the menu bar and rename the document to:  
   **Smart Sensor contract comparison**

6. Leave the document open — you will add more content to it in the next steps.

> ✅ **Checkpoint:** You have a Word document named **Smart Sensor contract comparison** open in Word for the web, containing the initial contract comparison analysis.

> **📸 Screenshot placeholder:** Capture the Word for the web document open with the imported comparison content visible.  
> Suggested filename: `M05-Lab08-Step04-WordDocumentOpen.png`

### Step 5: Add an Executive Summary Section

You now want to add a concise Executive Summary at the beginning of the document for leadership readers.

1. In Word for the web, select **Copilot** on the **Home** tab ribbon.

2. Verify the **Edit with Copilot** icon (✏️) is visible in the prompt field. If not, select **(+)** → **Edit with Copilot**.

3. **Place your cursor** at the very beginning of the document (before the first section). Insert a blank line and position your cursor there.

4. **Write and submit your own prompt** asking Copilot to add an **Executive Summary** section at the cursor position that:
   - Provides a summarized analysis of both vendor contracts.
   - Indicates which contract has more favorable terms for Fabrikam, and explains why.
   - Highlights where Fabrikam should focus its negotiation efforts.

**After Copilot responds:**
- Review the Executive Summary added to the document.

> ✅ **Expected Outcome:** A new Executive Summary section at the top of the document that provides a leadership-ready overview of the contract comparison findings.

> **📸 Screenshot placeholder:** Capture the document after the **Executive Summary** section has been added near the top.  
> Suggested filename: `M05-Lab08-Step05-ExecutiveSummaryAdded.png`

### Step 6: Add a Focused Analysis Section — First Contract Area

Finance professionals who review supplier contracts typically examine several important areas beyond basic pricing and delivery. Choose **one** of the following topics that interests you most for a deeper analysis:

| Contract Analysis Area | Key Questions to Address |
|----------------------|--------------------------|
| **Termination and exit clauses** | Notice periods, early termination penalties, handling of outstanding obligations |
| **Volume flexibility and scalability** | Provisions for adjusting order volumes, price breaks at higher volumes, minimum order quantity changes |
| **Change management and amendments** | How contract changes or specification updates are handled; regulatory change processes |
| **Supplier performance and monitoring** | KPIs, SLAs, remedies for underperformance, performance review process |
| **Compliance and regulatory requirements** | Industry standards, audit rights, regulatory compliance obligations |
| **Dispute resolution** | Arbitration, mediation, jurisdiction for contract disputes |
| **Financial health and stability** | Clauses for financial ratios, insurance levels, change of control / financial distress |

1. **Select your cursor position** in the document where you want the new section to appear.

2. **Write and submit your own prompt** asking Copilot to add a new section that compares the Adatum and Contoso contracts specifically on your chosen topic.

> 💡 **Tip:** Focusing on a single topic at a time consistently produces more thorough and precise analysis than asking Copilot to compare multiple areas in one prompt.

**After Copilot responds:**
- Review the new section.

> ✅ **Expected Outcome:** A new section added to the document that provides a detailed comparison of both contracts for your selected topic.
